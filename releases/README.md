# Windows and Linux development releases

`Pilotwings64Recompiled-Windows.zip` contains the native Windows x64 program, launcher resources, runtime libraries, and license notices. It contains **no ROM**. Extract the entire archive before launching the EXE.

Provide your own supported US ROM through the launcher. See the main [README](../README.md) and [build instructions](../BUILDING.md).

`SHA256SUMS.txt` records the package checksum. This folder is committed for local review and later publication; no GitHub Release is created automatically.

`Pilotwings64Recompiled-Linux-x64.zip` is the native Linux package for Ubuntu 24.04-compatible x86-64 systems. See [Linux setup](../LINUX-README.md). Both ZIPs exclude the ROM.
